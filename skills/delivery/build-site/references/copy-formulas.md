# Copy formulas

Use these as scaffolds, not templates to fill in mechanically — every
example below should get rewritten with specifics from the actual intake
before it ships. A formula with the client's actual name and service
swapped in for placeholders is still generic filler if nothing else
changes.

## Hero headline

**Formula:** `[Service] in [Service Area], [reassurance tied to the fear
from the interview]`

- Generic (avoid): "Your Trusted Local HVAC Experts"
- Specific (aim for): "Same-Day Furnace Repair in Saskatoon — Licensed
  Techs, No Surprise Charges"

The second version works because it answers a fear (surprise charges,
slow response) that the interview should have surfaced — not because it's
longer.

## Service description (per card or per service page)

**Formula:** `What it is → who it's for / when they need it → the one
thing that makes this client's version of it different`

Example shape: "Furnace won't start? We diagnose and repair same-day for
most Saskatoon-area calls, and we tell you the price before we start —
no hourly surprises."

Avoid stacking adjectives ("comprehensive, professional, reliable
furnace repair services") — none of them are falsifiable, so none of them
persuade.

## The "why us" section, built from the fear answer

Structure: **name the fear plainly → state the specific thing the client
does that addresses it → make it verifiable if possible**

- Fear: "unlicensed or fly-by-night contractor"
  → Copy: "Fully licensed and insured in [province/state] — ask to see
  our license number, it's on every invoice."
- Fear: "overcharged / hidden fees"
  → Copy: "Flat-rate pricing quoted before we start. What we quote is
  what you pay."
- Fear: "no-show / ghosted after booking"
  → Copy: "Text confirmation the morning of your appointment, every
  time."

Don't invent a fear the client didn't actually name in the interview —
if step 1 of `SKILL.md` came back thin on this, go back and ask rather
than guessing at a generic one.

## CTA button copy

Avoid "Submit" and "Learn More" — neither states the outcome.

- Prefer action + benefit: "Get My Free Quote", "Book a Same-Day Call",
  "Talk to a Tech Now" (only if a phone actually rings live — don't
  promise immediacy the client can't deliver).

## What "generic filler" looks like (cut these on sight)

- "Your trusted local experts"
- "We take pride in our work"
- "Customer satisfaction is our #1 priority"
- "Serving the community for years" (use the actual number instead)
- Any sentence that would be equally true if you swapped in a
  competitor's name
